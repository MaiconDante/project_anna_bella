# 🌟 Site Anna Bella

Este projeto foi desenvolvido durante o curso **Desenvolvimento Web Completo** da Udemy, com o objetivo de praticar conceitos fundamentais de HTML5 e CSS3 na construção de um site estático moderno.

## 📷 Demonstração
**URL:** -> <a href="https://maicondante.github.io/Projeto_Anna_Bella/">Projeto Anna Bella</a>

---

## 📚 Sobre o Projeto

O Site Anna Bella é uma simulação de um site profissional para uma modelo fictícia, desenvolvido para aplicar conceitos de estruturação de páginas web com HTML5 e estilização utilizando CSS3.

O projeto utiliza uma abordagem mais moderna em comparação aos exercícios anteriores do curso, empregando tags semânticas e uma folha de estilos externa para promover melhor organização, manutenção e reutilização do código.

---

## 🛠️ Tecnologias Utilizadas

* HTML5
* CSS3
* Tags semânticas
* Folha de estilo externa (`style.css`)

---

## 🧱 Estrutura do Site

O projeto é composto pelas seguintes páginas:

* 🏠 Home
* 👤 Biografia
* 📸 Campanhas Publicitárias
* 📞 Contato

Todas as páginas compartilham uma identidade visual consistente, proporcionando uma navegação simples e intuitiva ao usuário.

---

## 🎯 Objetivos de Aprendizagem

Durante o desenvolvimento deste projeto foram praticados conceitos como:

* Estruturação de páginas com HTML5
* Utilização de tags semânticas
* Criação e organização de arquivos CSS externos
* Estilização de elementos visuais
* Navegação entre múltiplas páginas
* Organização de imagens e recursos do projeto
* Boas práticas de separação entre estrutura e apresentação

3. Abra o arquivo `index.html` em seu navegador.
